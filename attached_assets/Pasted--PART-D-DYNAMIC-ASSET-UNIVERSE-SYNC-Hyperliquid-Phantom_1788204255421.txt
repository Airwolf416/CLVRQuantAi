2. New module server/lib/assetUniverse.ts:
   - Fetch POST https://api.hyperliquid.xyz/info body {"type":"meta"} for the
     full perp universe (name, szDecimals, maxLeverage), and
     {"type":"metaAndAssetCtxs"} for per-asset dayNtlVlm (24h notional volume),
     openInterest, funding, markPx.
   - Persist to a new table asset_universe (symbol, maxLeverage, dayVolumeUsd,
     openInterestUsd, isEquityPerp boolean, status 'active'|'quarantine'|'delisted',
     firstSeenAt, lastSeenAt, updatedAt).
   - Refresh job every 6 hours + on server boot. Symbols missing from the meta
     response for 2 consecutive refreshes → status 'delisted' (never emit, keep
     history). HIP-3 equity perps → isEquityPerp=true.

3. TIERED ADMISSION (critical — do not skip):
   - LIQUIDITY FLOOR: only assets with dayVolumeUsd >= $25M AND
     openInterestUsd >= $5M are eligible for signal emission at all.
     Below floor → status stays 'quarantine'; scanner may still track prices
     but every emission path must reject with empty_reason detail LOW_LIQUIDITY.
   - NEW LISTINGS: any symbol first seen < 30 days ago is treated as
     off-whitelist in the existing token soft gate (conviction capped, flag
     'new-listing') even if it clears the liquidity floor. It graduates only
     when the shadow calibration (Part C) has n >= 25 resolved signals for it
     OR 30 days elapse with the floor continuously met.
   - EQUITY PERPS (isEquityPerp): eligible for scanning but tagged so the
     macro gate uses the equity-relevant context (DXY, index futures, earnings
     proximity via earnings_cache) instead of the BTC 4-hour move. If that
     wiring doesn't exist yet, exclude equity perps from emission with
     empty_reason detail EQUITY_CONTEXT_PENDING rather than emitting with a
     crypto-only macro gate.

   - Respect Hyperliquid rate limits: single metaAndAssetCtxs call returns all
     asset contexts at once — use it instead of per-asset calls wherever possible.
   - Candidate pre-filter BEFORE any AI/scoring spend: only assets passing the
     liquidity floor AND showing a minimum 4h |move| or funding/OI anomaly enter
     the scoring pipeline. Everything else is skipped silently that cycle.
